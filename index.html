0符号约定与总纲

先统一记号，后面所有公式都不再解释字母含义。

记号含义记号含义
A（现期）本期 / 报告期的量a分子（部分、总数）的增长率
B（基期）对比期 / 上年同期的量b分母（整体、份数）的增长率
r增长率（可为负，下降时 r < 0）n年份差 = 末年 − 首年
Δ增长量 = A − Bpp百分点（百分数的绝对差）
母公式　A = B × (1 + r)　　一切公式的根
变形一　B = A ÷ (1 + r)
变形二　Δ = A − B = B × r = A × r/(1 + r)
变形三　r = (A − B) ÷ B = A/B − 1
比值通式　C = A/B（部分/整体、总数/份数、A是B的几倍，全是它）
　　C 的基期值 = C现 × (1 + b)/(1 + a)
　　C 的增长率 = (a − b)/(1 + b)
　　C 的两期绝对差 = C现 × (a − b)/(1 + a)
一句话记住三个「两期」：求基期值统一乘 (1+b)/(1+a)；求增长率统一除 (1+b)；求差多少个百分点统一除 (1+a)。分母是分子增长率还是分母增长率，取决于你要的是「相对增速」还是「绝对差」。
适用增长率、比重、平均数、倍数这四类题，本质是同一个 A/B 结构，所以三个通式可以一套打天下。遇到任何「两期比较」的题，先认清 A（分子）和 a（分子增速），套完再算。

2十二组公式族

按知识点拆分，每组给出完整公式、推导口径和使用条件。这节是「字典」，第 3 节是「怎么用它做题」。

2.1 增长三兄弟：现期、基期、增长量、增长率

A = B(1+r)　　B = A/(1+r)　　Δ = Br = A·r/(1+r) = A − B　　r = Δ/B = A/B − 1
由 Δ 反推： B = Δ/r　　A = Δ(1+r)/r
下降时： r 取负值，「同比下降 8%」→ r = −8%，B = A/(1−8%) = A/0.92
最重要的一条变形：Δ = A × r/(1+r)。资料里通常给「现期值 + 增长率」，求增长量时用它一步到位，不必先算基期。
把 r 化成分数 1/n，则 Δ = A/(n+1)、B = A·n/(n+1)。例：r = 25% = 1/4，Δ = A/5，B = 4A/5；r = 20% = 1/5，Δ = A/6。

2.2 同比、环比与隔年增长

概念定义易错点
同比与上年同期比（2023年3月 vs 2022年3月）跨年、消除季节性
环比与上一个相邻周期比（3月 vs 2月）「比上月」= 环比
隔年增长率R = r₁ + r₂ + r₁·r₂不能简单相加，交叉项必须算
隔年基期两年前 = A/[(1+r₁)(1+r₂)] = A/(1+R)r₁ 是前年→去年的增速
速算：r₁r₂ 很小可先忽略估个大概，再结合选项。如 r₁=10%、r₂=20% → R = 32%（10+20+2）；若 r₂ 为负（−5%），R = 10% − 5% − 0.5% = 4.5%。

2.3 比重（现期 / 基期 / 两期差 / 升降判断）

设部分现期 A、整体现期 B，部分增速 a、整体增速 b。

现期比重　A/B × 100%
部分 = 整体 × 比重　　整体 = 部分 ÷ 比重
基期比重　(A/B) × (1+b)/(1+a)
两期比重差　(A/B) × (a−b)/(1+a)　单位：百分点，正为升、负为降
升降判断　a > b → 上升；a < b → 下降；a = b → 不变
考场秒杀技巧：两期比重差的题，先判方向（a 与 b 比大小）排除一半选项；再用「结果一定小于 |a−b|」定范围（因为 A/B < 1 且除以 1+a 会再缩小），往往不用动笔就能选出答案。只有选项都非常接近时才需要精算。

2.4 平均数（现期 / 基期 / 增长率 / 增长量）

设总数 A（增速 a）、份数 B（增速 b），平均数 C = A/B。

现期平均数　A/B
基期平均数　(A/B) × (1+b)/(1+a)
平均数增长率　(a−b)/(1+b)　　　相对变化，分母是份数增速
平均数增长量　(A/B) × (a−b)/(1+a)　绝对差，分母是总数增速
升降判断　a > b → 平均数上升；a < b → 下降
最容易混的一组：两期比重差与平均数增长量形式相同（都除 1+a），但「平均数增长率」和「比值增长率」除的是 (1+b)。判断标准：题目问「百分之几」→ 求增长率 → 除 (1+b)；问「多少个百分点 / 多少元」→ 求绝对差 → 除 (1+a)。

2.5 倍数与比值

A 是 B 的几倍　A/B　　　　A 比 B 多几倍　A/B − 1
A 比 B 多百分之几　(A−B)/B = A/B − 1　与「多几倍」同式，只是换单位
基期倍数　(A/B) × (1+b)/(1+a)
倍数 / 比值的增长率　(a−b)/(1+b)
「A 是 B 的 3 倍」 ⇔ A 比 B 多 2 倍 ⇔ B 比 A 少 2/3
「A 是 B 的 n 倍」与「A 比 B 多 n 倍」相差 1，是资料分析最高频的文字陷阱之一。另外注意「A 不足 B 的一半」「超过 B 的两成」这类需要放缩的表述。

2.6 年均增长量与年均增长率

n = 末年 − 首年　年份差，不是年份个数
年均增长量　(A末 − A初)/n
年均增长率　(1+x)n = A末/A初　→　x = ⁿ√(A末/A初) − 1
估算　x < (A末/A初 − 1)/n　复利效应使真实值略小，n 越大偏差越大
代入验证　用选项中间值算 (1+x)n，与 A末/A初 比对
「五年规划」口径的坑：若题目说「十三五期间（2016—2020）年均增长量」，资料通常给 2016—2020 各年数值 + 2015 年数值，此时基期取 2015，n = 5，用 (2020−2015)/5；若只给 2016—2020 五年数值并问「这五年年均增长量」，则 n = 4，用 (2020−2016)/4。以题干给的年份跨度和可比基期为准，别死记 4 或 5。

2.7 混合增长（十字交叉 / 线段法）

整体由两部分构成，各部分基期量 A、B，增长率 a、b（设 a > r > b），整体增长率 r。

整体增长率范围　min(a,b) < r < max(a,b)，且偏向基期量大的一方
十字交叉　A基期 : B基期 = (r − b) : (a − r)
推导　Aa + Bb = (A+B)r　⇒　A(a−r) = B(r−b)
常用场景　进出口总额 = 进口 + 出口；城乡合计 = 城镇 + 乡村；一二三产合计；男女性别合计
注意交叉比出来的是基期量之比，不是现期量之比。若题目问现期量之比，需再各自乘 (1+a)、(1+b) 换算。

2.8 贡献率与拉动增长

贡献率 = 部分增长量 / 整体增长量 × 100%
拉动增长（百分点） = 部分增长量 / 整体基期量 × 100%
二者关系　拉动点数 = 贡献率 × 整体增长率
推论　各部分贡献率之和 = 100%；各部分拉动点数之和 = 整体增长率
区分分母：贡献率分母是「整体的增长量」，拉动增长分母是「整体的基期量」。记「贡献分增量，拉动分基期」。

2.9 百分数与百分点

百分数百分点
本质两个数的比值两个百分数的差值
运算乘除加减
典型问法「占比为 20%」「增长 8%」「比重提高 2 个百分点」「增速回落 3 个百分点」
「增速由 10% 提高到 12%」= 提高 2 个百分点，但增速本身提高了 20%（(12−10)/10）。「降幅收窄 3 个百分点」= 增长率由 −8% 变成 −5%，不是 −8%×(1−3%)。

2.10 番数、成数、指数

翻 n 番 = 2n 倍（翻一番 2 倍、翻两番 4 倍、翻三番 8 倍）
成数　1 成 = 10%；「增长三成」= r = 30%；「三成多」= 30%~40%
指数　指数 = 现期值/基期值 × 100；增长率 = 指数/100 − 1
两期指数比较　增长率 = I₂/I₁ − 1　不能直接把指数相减当增长率
定基指数（如「以 2015 年 = 100」）中，2022 年 102、2023 年 105，则 2023 年同比增速是 105/102 − 1 ≈ 2.94%，不是 3%；「比上年 = 100」的指数才能直接减 100。

2.11 专用统计术语速记

贸易类

进出口总额 = 进口 + 出口；顺差 = 出口 − 进口；逆差 = 进口 − 出口；顺差额 = 出口 − 进口。求「顺差同比增长」用 Δ/基期顺差，注意顺差基数可能很小甚至是负。

企业经营类

利润率 = 利润/营业收入；成本利润率 = 利润/成本；产销率 = 销量/产量；资产负债率 = 负债/资产；产能利用率 = 实际产量/产能。

人口与社会类

城镇化率 = 城镇人口/总人口；自然增长率 = 出生率 − 死亡率；恩格尔系数 = 食品支出/消费支出；人均 = 总量/人口数。

结构类

比重 = 部分/整体；三大产业增加值之和 = GDP；「占比较上年提高」用 2.3 节公式；「拉动」「贡献」用 2.8 节公式。

这些术语本身不是公式，考的是「能否把文字翻译成分数」。翻译对了，剩下的都是除法。

2.12 增长量 / 增长率的大小比较

大大则大　现期大且增长率大 → 增长量一定大（无需计算）
一大一小　比较 A×r/(1+r)，把 r 化 1/n 后比较 A/(n+1)
增长率比较　比较 A/B − 1，本质是分数比大小：直除 / 化同 / 差分法
倍数法　Δ₁/Δ₂ = (A₁/A₂) × [r₁/(1+r₁)] ÷ [r₂/(1+r₂)]
例：甲 1200 增 8%，乙 900 增 25%。乙现期小但增速大：甲 Δ ≈ 1200/13.5 ≈ 89，乙 Δ = 900/5 = 180，乙大。凡「大大则大」不成立，就必须算，别凭直觉选现期大的。

3十五类题型与逐题解析

每类给出：识别标志 → 公式 → 例题 → 分步解析 → 易错点。例题数字均为便于口算的设计值，重点在看方法。

01基期值计算最高频
识别题干出现「XX 年为多少」「上年同期为多少」，资料给的是本期值 + 同比增速。
B = A / (1 + r)
例2023 年某省 GDP 为 6.3 万亿元，同比增长 5.0%。2022 年该省 GDP 约为多少万亿元？
解析：B = 6.3/1.05 = 6.0 万亿元。
速算：1/1.05 ≈ 1 − 5% + 0.25% ≈ 0.9524，6.3 × 0.9524 = 6.0。化除为乘：A/(1+r) ≈ A(1−r)，r 小时误差仅 r²（此处 0.25%）。
坑：r 为负时是「除以 1−|r|」，即「同比下降 5%」→ 6.3/0.95 ≈ 6.63，基期比现期大。很多人误乘 (1+r) 直接算成现期。
02现期值 / 预测值计算基础
识别「按此增速，下一年为多少」「若保持该增长量，将达到」。
A = B(1 + r)　或　A = B + Δ（保持增量时）
例2022 年 A 产品产量 800 万吨，2023 年同比增长 12%，2024 年若保持该增速，产量约为多少？
解析：2023 = 800 × 1.12 = 896；2024 = 896 × 1.12 = 1003.52 万吨。
若题干是「保持增量不变」，则每年加 96 万吨，2024 = 992 万吨。增速不变 ≠ 增量不变，这是本题唯一考点。
坑：多年预测要用复利 (1+r)ⁿ，不能写成 B(1+nr)。
03增长量计算必考
识别问「增长了多少 亿元 / 万人 / 吨」，答案带具体单位。
Δ = A × r/(1 + r) = A/(n + 1)　（r = 1/n 时）
例2023 年某企业营收 420 亿元，同比增长 20%。2023 年营收比上年增加多少亿元？
解析：r = 20% = 1/5 → Δ = 420/(5+1) = 70 亿元。
验证：B = 420/1.2 = 350，Δ = 420 − 350 = 70。
若 r = 25%，Δ = A/5；r = 33.3%，Δ = A/4；r = 10%，Δ = A/11。百化分是这一题型的秒杀钥匙。
坑：别用 420 × 20% = 84。乘现期得到的是「基期 × r 的高估值」，正确分母必须是基期。
04增长率计算基础
识别问「同比增长百分之几」「增速 / 增幅为」。
r = (A − B)/B = A/B − 1
例2022 年某指标 1300，2023 年 1560。2023 年同比增长百分之几？
解析：Δ = 260，r = 260/1300 = 20%。或 1560/1300 − 1 = 1.2 − 1 = 20%。
坑：分母必须是基期。若问「2022 年比 2023 年少百分之几」，分母换成 1560 → 260/1560 ≈ 16.7%，答案完全不同。看准「比」字后面是谁。
05增长量 / 增长率比较常考排序
识别「增长最多 / 最少」「增速最快 / 最慢」「增量最大的是」。
比增长率：A/B − 1　　比增长量：A × r/(1+r)
例甲：现期 1200，同比增 8%；乙：现期 900，同比增 25%。谁的增量更大？
解析：8% ≈ 1/12.5 → 甲 Δ ≈ 1200/13.5 ≈ 89；25% = 1/4 → 乙 Δ = 900/5 = 180。乙大。
思路：现期大、增速也大 → 直接判（大大则大）；一大一小必须算，且用「现期 ÷ (n+1)」最快。
四个选项时要先扫一眼有没有「大大则大」能直接排除的；增长率比较题优先用直除取首位，不必算完整小数。
06现期比重与部分/整体还原必考
识别「A 占 B 的比重」「占比为多少」；或反向「已知比重求部分/整体」。
比重 = A/B　　部分 = 整体 × 比重　　整体 = 部分 ÷ 比重
例2023 年某省第一产业增加值 2.4 万亿元，GDP 为 12 万亿元。第一产业占 GDP 的比重为多少？
解析：2.4/12 = 20%。反向：若已知第二产业占比 40%、GDP 12 万亿，则第二产业 = 12 × 40% = 4.8 万亿；若已知某产业 3 万亿、占比 25%，则 GDP = 3/0.25 = 12 万亿。
坑：「A 占 B」与「B 占 A」分母相反；饼图中「其它」项常需 100% 减去已知各项之和。
07基期比重高频难点
识别「上年同期 A 占 B 的比重约为」。
基期比重 = (A/B) × (1 + b)/(1 + a)
例2023 年 A 产业增加值 2.4 万亿（同比增 8%），GDP 12 万亿（同比增 5%）。2022 年 A 产业占 GDP 比重约为？
解析：现期比重 = 2.4/12 = 20%；
基期比重 = 20% × 1.05/1.08 ≈ 20% × 0.9722 ≈ 19.44%。
验算：基期 A = 2.4/1.08 ≈ 2.222，基期 GDP = 12/1.05 ≈ 11.429，2.222/11.429 ≈ 19.44%。
速判：a(8%) > b(5%)，部分长得比整体快 → 比重上升 → 基期比重一定小于 20%，可先排除大于 20% 的选项。
08两期比重差 / 比重升降判断秒杀题
识别「比重比上年提高 / 下降多少个百分点」「比重上升的有几个」。
Δ比重 = (A/B) × (a − b)/(1 + a)　　方向：a > b 升，a < b 降
例承上例（现期比重 20%，a = 8%，b = 5%），2023 年 A 产业占 GDP 比重比上年约提高多少个百分点？
解析：Δ = 20% × (8% − 5%)/(1 + 8%) = 20% × 3%/1.08 ≈ 0.56 个百分点。
与题型 07 结果对照：20% − 19.44% = 0.56pp，一致。
三级秒杀：① a > b → 上升，排除所有「下降」选项；② 结果必小于 |a−b| = 3pp；③ 因乘了 20%，结果远小于 3pp，通常只有 0.5~0.6 量级，直接锁定。
坑：答案单位是百分点不是百分数；选项常同时放「0.56%」和「0.56 个百分点」混淆。另外分母是 (1+a) 而不是 (1+b)。
09平均数（现期 / 基期 / 增长率 / 增长量）高频难点
识别「平均每家 / 人均 / 单位面积产量 / 每万人拥有」。
C = A/B　基期 C = (A/B)·(1+b)/(1+a)　增长率 = (a−b)/(1+b)　增长量 = (A/B)·(a−b)/(1+a)
例2023 年某行业营收 3600 亿元（同比 +20%），企业 1200 家（同比 +10%）。2023 年平均每家企业营收同比增长约百分之几？
解析：a = 20%（总数增速），b = 10%（份数增速）。
平均数增长率 = (20% − 10%)/(1 + 10%) = 10%/1.1 ≈ 9.1%。
验算：现均 = 3600/1200 = 3 亿；基期营收 = 3000，基期企业 = 1090.9，基均 ≈ 2.75 亿；3/2.75 − 1 ≈ 9.1%。
若改问「平均每家比上年增加多少亿元」：Δ = 3 × (20%−10%)/(1+20%) = 3 × 0.1/1.2 = 0.25 亿元。
坑：问百分之几除 (1+b)，问多少元除 (1+a)，这是与题型 08 并列的第一大失分点。另外分子分母别搞反（人均 = 总量/人数，不是人数/总量）。
10倍数与「多几倍」文字陷阱
识别「A 是 B 的几倍」「A 比 B 多几倍」「上年 A 是 B 的几倍」。
是几倍 = A/B　多几倍 = A/B − 1　基期倍数 = (A/B)·(1+b)/(1+a)
例2023 年 A = 600（同比 +10%），B = 150（同比 +5%）。2022 年 A 是 B 的多少倍？
解析：现期倍数 = 600/150 = 4 倍；
基期倍数 = 4 × 1.05/1.10 ≈ 3.82 倍。
验算：基期 A = 545.45，基期 B = 142.86，比值 = 3.82。
若问「A 比 B 多几倍」：现期多 3 倍；若问「A 与 B 的比值比上年提高百分之几」：(10%−5%)/(1+5%) ≈ 4.76%。
坑：「是几倍」和「多几倍」差 1；「A 是 B 的 3 倍」≠「B 是 A 的 1/3 倍」的口语误用；基期倍数要乘增速修正因子，不能直接拿现期倍数作答。
11年均增长量 / 年均增长率必考
识别「XX—XX 年年均增长」「平均每年增加」。
n = 末年 − 首年　年均增量 = (A末 − A初)/n　(1+x)ⁿ = A末/A初
例某指标 2018 年 500，2022 年 800。2018—2022 年年均增长量与年均增长率分别约为？
解析：n = 2022 − 2018 = 4（不是 5）。
年均增量 = (800 − 500)/4 = 75。
年均增速：(1+x)⁴ = 800/500 = 1.6。线性估算 60%/4 = 15%，真实值必小于 15%；代入 12.5%：1.125⁴ ≈ 1.602，故 x ≈ 12.5%。
坑：① n 用年份差；② 五年规划类题目基期可能要前推一年（见 2.6）；③ 年均增速不是各年增速的算术平均；④ 选项接近时用代入验证，不要用开方硬算。
12隔年增长中频
识别「2023 年比 2021 年增长」「两年前为多少」，材料给了连续两年同比增速。
R = r₁ + r₂ + r₁r₂　　两年前 = A/[(1+r₁)(1+r₂)] = A/(1+R)
例2022 年同比增 10%，2023 年同比增 20%。2023 年比 2021 年增长百分之几？若 2023 年为 660，2021 年为多少？
解析：R = 10% + 20% + 10%×20% = 32%。
2021 年 = 660/1.32 = 500。
验算：500 × 1.1 = 550，550 × 1.2 = 660。
坑：漏掉交叉项 r₁r₂，误答 30%；求两年前只除一次 (1+r)。若 r 为负（下降）交叉项符号也要跟着变。
13混合增长 / 十字交叉中频难点
识别整体由两部分构成，给了各部分增速和整体增速，求「两者之比」「判断整体增速范围」。
A基 : B基 = (r − b) : (a − r)，其中 a > r > b
例某年出口同比增 8%，进口同比增 4%，进出口总额同比增 6%。上年出口额与进口额之比约为？
解析：a = 8%，b = 4%，r = 6%。
出口基期 : 进口基期 = (6−4) : (8−6) = 2 : 2 = 1 : 1。
验算：设各 100，则整体基期 200，整体增量 100×8% + 100×4% = 12，r = 12/200 = 6%。
若 r = 7%，则比值 = 3 : 1，说明整体增速偏向权重大的一方（出口）。
坑：交叉比是基期量之比；整体增速必在两部分之间，若选项给 9% 或 3% 可直接排除。
14贡献率、拉动增长与专用术语概念题
识别「贡献率」「拉动…增长 X 个百分点」；或利润率、产销率、顺差、指数等陌生名词。
贡献率 = 部分Δ/整体Δ　拉动 = 部分Δ/整体基期 = 贡献率 × 整体r
例某省 GDP 同比增长 5%，全年 GDP 增量 500 亿元，其中工业增加值增量 200 亿元。工业对 GDP 增长的贡献率？拉动 GDP 增长多少个百分点？
解析：贡献率 = 200/500 = 40%；拉动 = 40% × 5% = 2 个百分点。
验算：整体基期 = 500/5% = 10000，200/10000 = 2%。
陌生术语一律「翻译成分数」：产销率 = 销量/产量，利润率 = 利润/营收，顺差 = 出口−进口，城镇化率 = 城镇人口/总人口。翻译对了就是除法题。
15综合判断与「无法推出」压轴题
识别「能够从资料中推出的是」「下列说法正确的是」，四个选项各考一个知识点。
策略：先易后难 → 先判方向/范围类，后算需要精算的 → 排除到剩一个即停
例材料给 2023 年 A 产业增加值 2.4 万亿（+8%）、GDP 12 万亿（+5%）、上年 A 产业增速 6%。判断：① 2023 年 A 占 GDP 比重高于上年；② 2022 年 A 产业增加值为 2.4/1.06；③ A 产业 2023 年增速比上年提高 2 个百分点；④ 2021 年 A 产业占比必低于 2022 年。
解析：① 8% > 5% → 比重上升，正确（秒判，不用算）。② 2022 年应为 2.4/1.08，错。③ 8% − 6% = 2 个百分点，正确（注意不是「提高 2%」）。④ 2022 年增速 6% 与当年 GDP 增速未知，无法比较 a 与 b，无法推出。
此类题正确的做法是先做 ① 这种一眼能判的，再逐项排，别一上来就硬算。
坑：④ 这种「数据不足」选项是命题人专门设的；「必」「一定」「均」等绝对化表述要格外警惕；选项里偷换同比/环比、百分数/百分点、增长量/增长率是三大常规干扰。

资料分析考的是「算得快且准」，不是算得精。下面五件工具覆盖了绝大多数计算。

配套用法：r ≈ 1/n → 增长量 = 现期/(n+1)，基期 = 现期 × n/(n+1)。例：增速 14.3% ≈ 1/7 → 增量 = 现期/8。反向也练：看到 9.1% 立刻想到 1/11。

4.2 截位直除

看选项差距定截位：选项首位不同 → 分子分母各截 2 位；首位相同、次位不同 → 截 3 位；选项非常接近 → 截 4 位或精算。
例：3568/12345 → 36/12 ≈ 3.0（若选项 2.1 / 2.9 / 3.6 / 4.2，直接选 2.9 附近）；分母截位时「四舍五入」，分子可同向微调以抵消误差。

4.3 化除为乘

A/(1+r) ≈ A × (1 − r)　　A/(1−r) ≈ A × (1 + r)　　误差约 r²，r < 10% 时基本可忽略
例：6.3/1.05 ≈ 6.3 × 0.95 = 5.985 ≈ 6.0；6.3/0.95 ≈ 6.3 × 1.05 = 6.615。增速超过 15% 时改用直除，避免误差累计。

4.4 分数比大小三法

直除法

各自除出首位/前两位，直接比。最通用，优先用。

化同法

把分子或分母化成相同（或相近）再比另一个。适合分子成倍数关系。

差分法

两分数 a/b 与 c/d（a>c, b>d），用「差分数」(a−c)/(b−d) 与大分数比较：差分数 > 小分数则大分数更大。适合两分数非常接近。

放缩法

问「超过/不足」时把分子放大或分母缩小定方向，不必算精确值。

4.5 估算与选项意识

  • 先扫选项：差距大就大胆估，差距小才精算。资料分析 80% 的题不需要算到底。
  • 两期比重差：先判方向 → 再用「小于 |a−b|」定范围 → 多数情况直接出答案。
  • 年均增长率：用「小于 (总增速/n)」排除偏大选项，再代入中间值验证。
  • 综合判断题：先做能秒判的选项（方向、范围、单位），算到唯一答案立刻停，别把四项全算完。
  • 单位换算：亿元/万元、%/‰、美元/人民币、同比/环比，动笔前先圈出来。

5十大高频陷阱

错了不是不会算，是没看清。考前过一遍这十条，比多刷十套题有用。

#陷阱正确做法
01时间错位看清「同比 / 环比」「比上年 / 比上月」；基期年份要准确前推；五年规划基期可能前推一年。
02百分点 vs 百分数「提高 2 个百分点」用加减；「提高 2%」用乘除。降幅收窄/扩大同理。
03增长量 vs 增长率「增长最多」比 Δ，「增长最快」比 r；带单位的是量，带 % 的是率。
04是几倍 vs 多几倍是几倍 = A/B；多几倍 = A/B − 1。
05两期公式分母搞反求「增长率 / 百分之几」除 (1+b)；求「百分点 / 多少元」除 (1+a)；求基期值乘 (1+b)/(1+a)。

09「占」的主体反了「A 占 B」= A/B；饼图/表格中先圈出整体是谁；多个整体别混用。

还有两个隐蔽的：① 十字交叉得出的是基期量之比；② 定基指数两期相减不等于增长率，要相除。

2天津卷七大特色

与联考通用卷对比，天津真正「不一样」的地方：

01 政治理论独立成模块

2026 大纲明确列出「政治理论、常识判断、言语、数量、判断、资料分析」六部分。考党的创新理论、二十大报告、中国式现代化，且常结合京津冀协同发展中天津的定位。这是近两年最大结构变化。

02 判断推理 35 题十年不动

图形 5 / 定义 10 / 类比 10 / 逻辑 10。题量固定意味着考点必须往细里考，「考点细化」是天津命题的主线。

03 类比推理三重叠加

一级关系只是入场券；二级辨析（词性、感情色彩、必然/或然、物理/化学）＋学科常识（物理化学生物文学）＋成语结构（主谓宾、典故主客体）叠加出题。2026 考后评价是「每个字都认识，凑一块儿不知道啥关系」。

04 图形推理偏爱立体空间

除数量、位置、样式、六面体外，截面图、三视图、立体拼合、不规则立体「外表面折叠」考查逐年增多。常规考点也细化：数点结合内外结构、数面看最大面/相同面、多个小元素对称轴之间的关系。

05 定义判断爱用诗词成语做选项

给一个心理学 / 管理学定义，四个选项直接是古诗词或成语，要求判断哪句符合定义。光会拆「主体客体」不够，还得读懂诗句。单定义远多于多定义。

06 素材高度本地化

常识考杨柳青年画、海河治理、渤海湾生态、自贸区政策；资料分析用天津港吞吐量、制造业产值、进出口额、京津冀统计公报；言语材料涉及天津城市发展与文化传承。

07 申论分类命制 + 专业科目

申论按市级区级综合管理类 / 乡镇街道综合管理类 / 行政执法类分别命制，专业技术类同市级区级。公安、审计、统计、外事等职位加试专业科目，成绩按 40:30:30 或 25:25:50 合成。

补充：数量关系不考数字推理

天津数量关系以数学运算为主，数字推理基本不考（近年高频：几何、排列组合、基础应用题、工程、利润、概率）。别按保留数推的省份去准备。

4二级辨析全表（本手册核心）

二级辨析 = 一级关系无法排除到唯一答案时，对词语做的第二层比较。下面 24 个角度覆盖了天津卷近年全部考法。

4.1 辨析优先级（按顺序试，别跳）

① 词性 / 词语结构（名词 vs 动词、主谓宾 vs 动宾、语序）
② 感情色彩（褒 / 贬 / 中）与程度递进
③ 主体（是否同一主体、是否职业、主动/被动）
④ 必然 / 或然（组成、原材料、属性、因果）
⑤ 物理变化 / 化学变化（工艺类专属）
⑥ 主要 / 次要功能、内在 / 外在属性、核心 / 非核心部件
⑦ 特指 / 泛指、人工 / 天然、命名方式、时间先后、场所是否唯一
⑧ 纵向同类比较（与题干属于同一类别的优先）——最主观，放最后用
为什么必须按序：一道题往往同时满足多个二级角度，但出题人只认一个。天津 / 国考通用的命题惯例是「先客观后主观」——词性、色彩、主体是硬事实，人工天然、命名方式属软判断，纵向同类最软。按顺序试到第一个能分出胜负的就停。

包容（通用）纵向同类比较把选项与题干纵向比，同类别优选。如「城市公园∶公共设施∶休闲娱乐」→ 选「医用口罩∶卫生用品∶过滤空气」。
对应 · 原材料必然 vs 或然材料木门∶木头（必需）；花瓶∶塑料（可选）。
对应 · 原材料人工 vs 天然 / 动植物来源檀香∶麝香∶香料：植物香料 + 动物香料 → 选「木材∶钢筋∶建材」（天然 + 人造），排除「薯条∶粉条」（可同为马铃薯）。
对应 · 工艺物理变化 vs 化学变化最常考的二级角度之一。物理：雕刻、打磨、编织、捆绑、蒸馏、裁剪；化学：发酵、燃烧、冶炼、锻造、酿造。冰块∶雕刻∶冰雕 → 选「原油∶蒸馏∶煤油」。
对应 · 功能主要功能 vs 次要功能灯具∶照明（主）／灯具∶装饰（次）。电磁感应∶发电机∶电能转换（2026 天津）考的就是「核心功能」而非附带功能。
对应 · 属性必然 vs 或然属性盐∶咸（必然）；花∶红（或然）。
对应 · 属性内在 vs 外在属性火∶火热（内在必然）→ 排除「金∶金黄」（外在）。
对应 · 因果必然 vs 或然因果下雨∶地湿（较必然）；淋雨∶感冒（或然）。
对应 · 方式目的目的能否达成刻舟无法求剑；凿壁能偷光。两者都是方式目的，靠这一层区分。
对应 · 时间顺承主体是否一致购票∶乘车∶到达三动作同一主体 → 选「报名∶参赛∶领奖」，排除「下单∶付款∶送达」（送达主体不同）。顺承关系常与主客体结合考。
对应 · 场所场所是否唯一鸭子∶河（不唯一，还能在岸上）→ 选「飞机∶飞机场」（还能在天上），排除「火车∶轨道」（唯一）。
语法 · 主体是否为职业舞台∶道具∶演员：演员在舞台用道具且是职业 → 选「工厂∶机器∶工人」，排除学生 / 消费者（身份）。
语法 · 偏正词性 / 语序空前∶规模（偏正，规模为名词）→ 选「有序∶市场」；排除「配合∶默契」（语序反）、「激烈∶挑衅」（挑衅是动词）。
三词型 / 复合词项结构对应先定每一对的关系再整体比。城市公园∶公共设施∶休闲娱乐＝种属 + 功能；电磁感应∶发电机∶电能转换＝原理 + 应用设备 + 核心功能。

4.3 天津真题风格逐题解析

12026 天津 · 学科常识型三词题最难的一类
题电磁感应∶发电机∶电能转换
A. 光电效应∶太阳能电池∶光能转换　B. 压电效应∶传感器∶振动检测
C. 热电效应∶温差发电∶热能转换　D. 磁滞现象∶变压器∶能量损耗
解析：题干结构＝科学原理 → 应用设备 → 设备的核心功能。发电机以电磁感应为工作原理，核心功能是电能转换。
A：太阳能电池以光电效应为原理，核心功能光能转换，完全对应，当选。
B：传感器是一类设备统称，振动检测只是部分传感器的功能，非核心通用功能，排除。
C：「温差发电」是技术应用而非具体设备，词项类别不符，排除。
D：磁滞现象是变压器运行中的负面现象（非工作原理），能量损耗是其结果而非功能，两层错位，排除。
答案 A。
天津特色这题「逻辑是骨架，常识是血肉」——光知道电磁感应是物理词没用，得知道它是发电机的技术依据。2026 类比整体偏常识化，涉及物理、化学、文学、生活常识，需专门积累科学原理与器件的对应（电磁感应/发电机、光电效应/太阳能电池、压电效应/传感器、热电效应/温差发电）。
22026 天津 · 人造物 + 核心部件二级辨析典型
题建筑∶房子∶房间
A. 汽车∶越野车∶车窗　B. 电器∶电视机∶屏幕　C. 医院∶私立医院∶医生　D. 餐具∶盘子∶筷子
解析：房子属于建筑（种属），房间是房子的组成部分（组成）。A、B 一级关系都成立，C 是「场所」、D 是「并列」，先排除。
二级辨析：房间是房子的核心 / 必需组成；车窗不是越野车的核心部件，屏幕是电视机的核心部件 → 选 B。
看到「人造物」词项（钢琴、房子、玻璃、汽车、镜子）优先试三类关系：功用关系（钢琴∶演奏 → 工具）、组成关系（房间∶房子）、加工关系（玻璃→镜子 / 灯具）。这是天津卷近年反复出现的题眼。
3成语结构题天津高频
题愚公移山∶郑人买履
A. 弄巧成拙∶囫囵吞枣　B. 杞人忧天∶庖丁解牛　C. 邯郸学步∶东施效颦　D. 凿壁偷光∶田忌赛马
解析：题干两词均为主谓宾结构（愚公/移/山，郑人/买/履）。
A：弄巧 + 成拙，两个动宾；C：邯郸是地点状语；D：凿壁 + 偷光，两个动宾 → 均排除。
B：杞人/忧/天，庖丁/解/牛，都是主谓宾 → 选 B。
成语题两条路：① 考语义关系（近义/反义/象征）→ 若有多项干扰，结合感情色彩和程度递进；② 考结构类型 → 直接拆主谓宾 / 动宾 / 偏正；③ 涉及典故 → 结合主客体与主要人物。
4象征关系 + 词性二级辨析经典天津题
题荆棘∶困难　A. 布衣∶学生　B. 折柳∶惜别　C. 心腹∶信任　D. 桎梏∶束缚
解析：荆棘象征困难，且「荆棘」为名词。A 布衣象征平民（非学生）、C 心腹指信任的人（非象征）→ 排除。B 折柳象征惜别、D 桎梏象征束缚，一级关系都成立。
二级辨析（词性）：折柳是动词，桎梏是名词 → 选 D。
5职业 / 身份二级辨析三词型
题舞台∶道具∶演员　A. 汽车∶驾驶∶司机　B. 操场∶足球∶学生　C. 商场∶商品∶消费者　D. 工厂∶机器∶工人
解析：造句「演员在舞台使用道具」。A 缺场所对应，排除；B、C、D 造句均成立。
二级辨析（是否职业）：演员是职业；学生、消费者是身份；工人是职业 → 选 D。
6场所唯一性二级辨析反直觉题
题鸭子∶河　（选项含）飞机∶飞机场　/　火车∶轨道
解析：鸭子与「河」是场所对应，但不唯一（鸭子还能在岸上）。飞机与飞机场同样不唯一（还能在天上）→ 当选；火车与轨道是唯一对应（在站台上也在轨道上）→ 排除。
答案：飞机∶飞机场。
这类题反直觉：很多人会选「看起来最紧密」的对应，但题干恰恰考「不唯一」。场所类纠结时一定加问一句「场所是否唯一」。
7工艺物理 / 化学二级辨析必背
题冰块∶雕刻∶冰雕　A. 爆竹∶点燃∶烟花　B. 原油∶蒸馏∶煤油　C. 纸张∶剪刀∶窗花　D. 木炭∶燃烧∶灰烬
解析：题干＝原材料 + 工序 + 成品，且雕刻是物理变化。
A：点燃爆竹得不到烟花，排除；C：剪刀是工具不是工序，排除；D：灰烬是残渣不是成品，且燃烧是化学变化，排除；B：原油经蒸馏（物理变化）得煤油 → 选 B。
速记：物理＝雕刻、打磨、编织、捆绑、蒸馏、裁剪、切割（无新物质）；化学＝发酵、酿造、燃烧、冶炼、锻造、氧化（有新物质）。这一组几乎每年都考。

4.5 三词型 / 括号型（天津卷常见形式）

三词型 A∶B∶C

逐对定关系，再整体比结构。常见结构：种属+功能（城市公园∶公共设施∶休闲娱乐）、原理+设备+功能（电磁感应∶发电机∶电能转换）、原材料+工序+成品（冰块∶雕刻∶冰雕）、大类+小类+组成（建筑∶房子∶房间）。

括号型 A 对于 ( ) 相当于 ( ) 对于 B

把选项逐一代入，前后两组关系必须一致。2026 天津真题：风驰电掣 对于 ( ) 相当于 ( ) 对于 锐不可当 → 选「鹅行鸭步；铩羽而归」，前后都是反义关系。常见陷阱是只有前半对、后半不对。

类比推理四条铁律：① 先一级后二级，绝不跳过一级；② 造句要严谨，不脑补额外信息；③ 二级辨析按 4.1 优先级顺序试，试出一个能分的就停；④ 题干是三词型时，注意词项顺序，顺序反了直接排除。

8截面图 / 三视图 / 立体拼合见下表「截不出的截面」

天津加码：不规则立体「外表面折叠」

特色给一个立体图形，问哪个选项是它的外表面展开图。三种方法：公共边等长法（重合的两条边长度必须相等）、公共点法（题干中有公共点的两条边，展开后仍须相交于一点）、公共边法（数面个数先排除，再核对应）。

考点细化的三种典型：数点结合内外结构（内外交点个数之差分组）、数面同时关注最大面特性 / 相同面关系、对称性考多个小元素对称轴的位置关系。天津分组分类题常走这条路。

6定义判断天津特色（10 题）

单定义为主

单定义远多于多定义。核心仍是拆「主体、客体、条件、方式、结果」，逐项比对。

诗词成语入选项

天津卷常见：给定义（如「对比联想」），四个选项直接是古诗词或成语。需要文学常识才能判断，纯技巧不管用。

领域分布

法律、经济、社会管理、心理学、自然科学类概念高频；2025 后更强调理解定义整体逻辑，光抠关键词不够。

备考动作

积累常见诗句的含义与情感（尤其含对比、反衬、借代、象征的），并练「定义要点 → 选项逐一打勾」的固定流程。

易错：选项里出现「好像符合但少了某个限定条件」的干扰项；以及问「不属于 / 不符合」时忘了反向选。先看设问再看定义，是这一模块最省时的习惯。

7逻辑判断天津特色（10 题）

题型权重天津考法与要点
削弱 / 加强绝对主力论点论据拆解、搭桥 / 拆桥、他因削弱、必要条件。选「最能削弱/加强」，要择优不是选「一定对」。
复言命题 / 翻译推理稳定出现「如果…那么」「只有…才」「且 / 或」的翻译规则与逆否等价；德摩根律。
朴素逻辑 / 组合排列常出现排除法、代入法、最大信息优先、列表法。耗时但可稳拿。
前提型 / 结论型 / 解释型轮换出现前提型用搭桥与必要条件；结论型注意「过度推断」；解释型找能同时兼容矛盾双方的选项。
可能性选项的处理：选「最能加强/削弱」时，若没有直接加强/削弱项，可择优选带可能性的选项；但问「不能削弱/加强」时，凡带可能性的选项一般都不选。这条规则在天津 / 国考通用。
常见坑：「否前」「肯后」不必然；「有的」不能推「所有」；诉诸权威、类比不当、样本偏差类选项看着有理但不构成加强。

8其他模块本地化与申论分类

天津市情素材清单（性价比极高的短期记忆点）

政治理论

党的二十大报告核心论断、中国式现代化的特征与本质要求、「十五五」规划重点任务、京津冀协同发展中天津的功能定位、新质生产力、双碳目标。

常识判断

天津历史文化遗产（杨柳青年画）、地域文化、海河治理工程、渤海湾生态保护、自贸区政策、天津港；新修 / 新实施的法律是稳定送分点。

资料分析

材料常取天津港吞吐量、制造业产值、进出口贸易额、京津冀经济统计公报。考点与通用卷一致（增长、比重、平均数、倍数），把上一份《资料分析公式速查手册》练熟即可。

言语理解

材料可能涉及天津城市发展、文化传承、社区养老等本地政策表述；逻辑填空约占四成，实词 / 成语 / 混合辨析各三分之一；主旨意图题占比高。

9备考优先级与时间分配

序模块建议用时理由 / 动作
1资料分析 20 题25 分钟单题分值最高、公式固定，目标正确率 ≥ 85%。每天 1 篇限时练。
2判断推理 35 题35 分钟题量最大且技巧性最强。类比 10 题目标 8+，靠二级辨析；逻辑判断是主要失分区。
3言语理解 25 题20 分钟逻辑填空靠易混词积累，主旨题靠转折 / 总结词定位。
4政治理论 + 常识 25 题20 分钟会就会，不会立刻跳过，别纠结。重点投天津时政与本地政策。
5数量关系 15 题20 分钟近年难度下调，不要整块放弃；主攻几何、排列组合、基础应用题，代入排除优先。
类比推理专项训练法
① 每天 20 道天津 / 联考类比真题，每道必须写出「一级关系」；
② 凡纠结两选项的，按 4.1 优先级逐个试角度，并记录最终用的是第几个角度；
③ 单独建「学科常识」清单：物理效应↔器件、化学变化↔工艺、成语结构、典故人物；
④ 一周后统计自己最常漏的 2~3 个二级角度，只补这几个。
时间观念：类比 10 题建议 5~6 分钟内做完，单题不超过 40 秒。想不出来就按优先级试完前三个角度直接择优，别在一道题上耗掉图推的时间。

10天津卷专属陷阱清单

#陷阱破解
01一级关系对了就选天津卷大量题目故意留 2 个一级关系都对的选项，必须做二级辨析。
02二级角度乱试按词性 → 色彩 → 主体 → 必然或然 → 物理化学 → 功能主次 → 纵向同类的固定顺序，试到能分即停。
03类比题里的学科常识电磁感应 / 光电效应 / 压电效应 / 热电效应对应什么器件，发酵与蒸馏哪个是化学变化，必须提前背。
04成语只看意思意思分不出时立刻拆结构（主谓宾 / 动宾 / 偏正）或看典故主客体。
05三词型漏看词项顺序「先 A 后 B 再 C」与「先 C 后 B 再 A」是不同关系；括号型必须前后两组同时成立。
06场所类凭直觉选「最紧密」加问「场所是否唯一」，题干可能恰恰考「不唯一」。
07图形推理只练平面天津加码截面图、三视图、立体拼合、不规则立体外表面折叠，单独练公共边等长 / 公共点法。
08定义判断读不懂诗句选项积累含对比、反衬、借代、象征的常见诗句；先看清问「属于」还是「不属于」。
09政治理论只背全国时政补「京津冀协同发展中天津定位」「天津市情与本地政策」，天津卷会往本地靠。
10数量关系整块放弃2025—2026 题量增到 15 且难度下调，基础题占六成，放弃等于白丢 4~5 分。
最后提醒：政治理论与常识的题量拆分近两年一直在调，考纲与考后回忆版口径不完全一致。上考场第一件事是翻一遍试卷，确认当年各模块实际题量，再调整时间分配，别按去年的数字硬套。
